# Financial Statement Analysis & Business Intelligence Dashboard

> An interactive financial analytics dashboard developed to automate financial statement analysis, ratio calculations, trend visualization, and business performance evaluation.

---

## Overview

This project develops an interactive dashboard for analysing financial statements of publicly listed companies using Python and Power BI.

The objective is to automate financial analysis performed by Equity Research Analysts, Investment Banking Analysts, Corporate Finance professionals, and Management Consultants.

The dashboard provides financial insights by analysing historical company performance across multiple reporting periods.

---

## Objectives

- Automate financial statement analysis
- Calculate key financial ratios
- Visualize historical performance
- Build an interactive dashboard
- Support equity research and valuation
- Improve financial decision-making
